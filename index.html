사서 땃쥐가 비공개 GitHub 서고에서 논문 노트를 꺼내 와, 어떤 논문끼리 지지하고 반박하고 확장하는지 실로 엮어 보여줘요. 이 페이지에는 논문 데이터가 없어요.

로그인 캐릭터 바꾸기

배경이 투명한 PNG가 가장 예뻐요. 이 브라우저에만 저장되고 어디에도 올라가지 않아요.

서고 열쇠(토큰) 만드는 법
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate
  2. Repository access: Only select repositories → Vault 저장소 하나
  3. Permissions → Repository → Contents: Read-only (나머지는 없음)
  4. 만료 기간은 30~90일 권장
토큰은 브라우저에서 api.github.com으로만 전송되며 URL이나 저장소에 기록되지 않습니다.
